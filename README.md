# 🏎️ Unity 3D Car Racing Game (Visual Scripting)

A 3D interactive car racing game built in Unity using Visual Scripting, featuring state machine transitions, score tracking, collision mechanics, and sound management.

---

## 📌 Features

* **Vehicle Navigation & Mechanics:** Custom axis-based movement controls for acceleration, braking, and steering.
* **Game Flow State Machine:** Seamless transitions between Start, Gameplay, Failed, and Level-Complete (Congratulations) scenes.
* **Collectibles & Score Tracking:** Coin collection system using trigger colliders and score variables.
* **Interactive Environments:** Static obstacle mechanics and boundary detection.

---

## 🛠️ Tech Stack & Tools

* **Engine:** Unity 3D
* **Logic:** Unity Visual Scripting (Flow Graphs & State Machines)
* **UI/UX:** Unity Scene Manager & UI Canvas

---

## 🎓 Academic Context & Reflection

Developed as coursework for the **Visual Programming** module at Westminster International University in Tashkent.

**Key Learnings & Retrospective:**
* Gained foundational understanding of event-driven flow graphs and scene state transitions.
* Identified the limitations of visual node-based scripting compared to object-oriented C# for complex game logic, driving my progression toward native C# and Python software development.
